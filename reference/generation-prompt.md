# How the reference SVGs were made

The files in `reference/svg` were not drawn by a designer. Each was generated by a language model
(ChatGPT, per the project owner) from the product photo plus three existing rosette SVGs chosen for
looking similar, with the prompt below. The model copied and adapted elements from the three examples,
which is why shapes repeat across the set. Some files may have been tweaked by hand afterwards
(layer moves, class changes) before testing on the shop.

Consequences for this project: the references define the layer and class contract and show the shape
vocabulary; where a reference deviates from its photo (tail widths, extra colors, omitted layers) that
is the generating model's choice, not a rule. The generation prompt mentions Colors 1 to 3 only.

## Prompt (verbatim)

Create an SVG file from the following PNG image by using the code of the provided SVG example images.
The SVG code of the generated image should follow the same logic like the one used for the example SVG
images. Consider using the same ids for the layers (<g> elements):
Layer_1 (color 1 solid elements)
Layer_3 (color 2 pattern + color 3 solid elements) (this layer is shown by our system when color 2 is a
pattern and hidden when color 2 is solid)
  Layer_3_2 (color 2 pattern elements)
  Layer_3_3 (color 3 solid elements)
Layer_2 (color 2 solid + color 3 solid elements) (this layer is shown by our system when color 2 is a
solid color and hidden when color 2 is a pattern)
  Layer_2_1_2 (color 2 solid elements)
  Layer_2_1_3 (color 3 solid elements)
And similar classes for the separate elements inside the layers which have the following structure
st{0-6}_{1-3}. The {0-6} part doesn't really matter to the system, it could be any digit from 0 to 6.
The st{0-6}_1 classes are used for the elements of solid color 1.
The st{0-6}_2_pattern classes are used for the elements of color 2 when it is a pattern.
The st{0-6}_2 classes are used for the elements of solid color 2 (no pattern).
The st{0-6}_3 classes are used for the elements of solid color 3.
As for the Layer_rose, please just feel free to copy it from one of the example SVGs.

Note: the live files use the group id `Layer_2_1` (not `Layer_2`) for the solid Color 2 group, as the
shop script `reference/shop-configurator.js` expects; the examples carried that id and the model kept it.
